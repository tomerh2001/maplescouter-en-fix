# MapleScouter audit, 24 September 2026

Release: **1.7.4**.

## Findings and changes

- Crawled 67 public routes and 188 current chunks. The two new routes are `/ability` and `/simulator/ability`. Compared with the previous baseline, 130 chunks changed. Extracted 7,211 Korean literals with no fetch or parse failures. No Korean literals exceeded the scanner's 1,000-character limit.
- Added 215 reviewed entries: 208 new strings and seven related label corrections. Coverage includes Inner Ability efficiency and simulation, Soul Potential and equipment repair, HEXA reset guidance, MVP Resort, Star Force restoration costs, account-based ranking filters, and the Surge-level error message.
- Added narrowly matched runtime translations for generated Inner Ability rolls, Circulator restrictions, probability explanations, accessible value ranges, and costs. Korean large-number amounts are converted as complete quantities. Game stats, probabilities and calculations are unchanged.
- Fixed ranking snapshot timestamps that previously mixed Korean hours with a combat-duration translation of minutes.
- English ability lines and cost buttons clipped or overlapped at phone width. Their containers now wrap and expand, scoped to the two new English ability routes.
- Reproduced a functional equipment-selection bug: the tooltip keep-alive cloned a closed slot dropdown. The clone had no React handlers, so it blocked opening the weapon-name list. Only informational tooltips and hover cards can now be pinned; menus, lists, dialogs and interactive controls are excluded. Escape dismisses a pinned tooltip, and clones cannot clone themselves.

## Validation

- 102 Node tests passed, including numeric/unit preservation, generated stat lines, Circulator constraints, reviewed dictionary output, ranking dates, existing cloud conflicts, passive-check timing, locale persistence and publishing safeguards.
- Both packages built as 1.7.4. Firefox lint: 0 errors, 0 notices, 11 existing warnings (Android minimum-version declaration and dynamic HTML assignments). No new permissions or build dependencies.
- Internal Chromium tests used the current site through an isolated local proxy. Compared the native live navigation with the patched site. Tested both new ability routes, target selection, a manual reroll, and a real expected-cost calculation. Reviewed desktop and 390px layouts; the phone page had no horizontal overflow and complete stat values and costs remained visible.
- Tested Item Maker slot selection followed by Genesis Dual Bowguns selection after the fix. The correct second menu opened, the old menu was absent, and Soul Potential rank/amplification controls were translated.
- Tested ranking's Main Characters Only filter and timestamp rendering. Added a reusable floating-layer fixture at `/en/__test/tooltip` on the local proxy: menu selection closes without a clone; informational tooltip text remains after native removal while hovered; Escape dismisses it, and moving the pointer away removes it.
- Created only an isolated local test character. Edited its level, reloaded, and confirmed the edit persisted. Downloaded its JSON and verified IGN, label, native envelope and level; imported the file and replaced that same local test character successfully. The browser download event timed out, but the downloaded file and successful re-import verified the actual operation.
- GMS selection survived a reload. Switching from English to Korean and back restored the English Character page. Result and Detailed Information opened in English. The current sample returned Normal 681,115,777 and Boss 380 Normal 102,682. With the sample's zero-level Surge, the site reports HEXA unavailable and returns an invalid negative aggregate. The extension translates the reason; it does not invent a HEXA value. This is not verification of numeric HEXA output for a valid fully configured character.
- A read-only production cloud HEAD check returned HTTP 200, an ETag and CORS headers. No production preset was created, overwritten or deleted. Cloud write/conflict handling was covered by the existing regression tests rather than production writes.

## Coverage and terminology

The final static scan has zero unresolved literals in its scanned set and the same 23 explained exceptions in `retained-korean.json`. Static coverage does not include every signed-in page or possible API response. Firefox runtime, authenticated scheduler flows, and every legacy calculator were not re-tested this week.

The new KMS Inner Ability rules were checked against [Nexon's current Inner Ability guide](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/392). Honor EXP, Attack Speed, Boss Damage, and the existing Circulator names use established MapleStory terminology. Advanced Reroll, Abyss Circulator, and Soul Amplification are descriptive translations for current KMS features, not claims that these names or mechanics have shipped in GMS.
