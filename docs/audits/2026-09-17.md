# MapleScouter audit, 17 September 2026

Release: **1.7.3**.

## Findings and changes

- Crawled 65 public routes and their 184 current JavaScript chunks, including 145 files not previously cached. Extracted 6,879 Korean literals. No route fetch or AST parse failures.
- The first pass found 567 uncovered literals. Added 555 reviewed entries, including 544 of those literals and 11 related wording/accessible-label fixes. This includes 184 complete potential probability tables. Tests verify every table's numeric values, odds columns and row count are unchanged.
- Translated the new stat quiz, class-analysis panels, pet controls, symbol migration messages, scheduler/server-save prompts, September patch labels, and equipment descriptions. Added accessible footer labels and corrected Jin-kae's name instead of translating it literally.
- Fixed exact DOM translation of whitespace-sensitive fragments and multiline tables. Added support for decimal Korean number units and complete HEXA skill-group labels.
- The new quiz's 48px equipment buttons clipped English words. Their labels now wrap and the five-column grid fits both desktop and phone cards.
- Found and reproduced an English-to-Korean regression when opening Detailed Information. Ordinary navigation now keeps the saved language; choosing a language in the native menu updates the preference before navigation. Reloads no longer misinterpret a site's fallback route as a language choice.
- Reworked the audit crawler to identify locale chunks only from the live build, not old cached versions. Fetches have timeouts and limited concurrency; locale JSON is decoded with an AST parser instead of eval. Added a reproducible parser dependency and reviewed live-build baseline for later runs.

## Validation

- 96 Node tests passed, including existing cloud/publishing checks, new language navigation regressions, numeric conversion, complete probability tables, interpolation and skill labels.
- Both packages built as 1.7.3. Firefox lint: 0 errors, 0 notices, 11 pre-existing warnings (Android minimum-version declaration and dynamic HTML assignments). No new permissions.
- Internal Chromium browser checks used the current site through the local test proxy and compared the unmodified live quiz. Covered Character controls, Result, Detailed Information, class analysis, the quiz and its hint action, and Core Skills Maker's symbols/pets. Inspected desktop and 390px phone layouts. Class-analysis tables scroll inside their card; the quiz has no page overflow and its equipment labels are no longer truncated.
- The sample Mercedes calculation returned Normal and HEXA values, including Boss 380 values of 102,682 and 65,753. Detailed Information loaded in English after the fix. This is a sample regression check, not a claim about every class's calculation.
- An initial local quiz request failed because the proxy's newly cached JavaScript bypassed its API-origin rewrite. Fixed the test proxy and confirmed a real quiz question and hint loaded. This was a test-setup failure.
- No production character saves were uploaded, changed or deleted. Firefox's live runtime and signed-in scheduler interactions were not re-tested in this audit; Firefox packaging was validated and the shared logic was covered by the regression suite.

## Coverage and terminology

The final static scan has no unresolved literals in the scanned set. Its 23 explained exceptions are listed in `retained-korean.json`: diagnostic logs, an author IGN, a character URL, number/stat fragments translated in complete expressions, and a required Korean video-submission tag. This does not guarantee coverage of all API content or signed-in states.

GMS terminology follows the existing ID-matched dictionary, including Decent Speed Infusion, Stunning Strikes, Sacred Symbols and Legion. New KMS-only labels such as Aurum Regis, Ascendant Pulse Ring, Luna skill names and collaboration pets use readable translations/transliterations until official GMS equivalents are available. They are not presented as verified GMS releases. The Argo event context was checked against [Nexon's September 17 update](https://m.maplestory.nexon.com/news/update/813).

## Release path

Pushing this version triggers the GitHub Release workflow and independent submissions to Chrome and Firefox. Submission receipts live in the Actions run. Approval remains with each store; the configured publishing mode makes the approved version available automatically.
